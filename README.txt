STUDENT MANAGEMENT SYSTEM

Technology:
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

Features:
1. Add student
2. View all students
3. Search student by ID
4. Update student
5. Delete student
6. Exit

How to run in Eclipse:
1. Create a Java Project named StudentManagementSystem.
2. Create two classes: Student and StudentManagementSystem.
3. Paste the corresponding code.
4. Run StudentManagementSystem.java as Java Application.

Main concepts used:
- Classes and Objects
- Encapsulation
- Constructors
- ArrayList
- Methods
- Loops and Switch
- Exception handling for invalid input
